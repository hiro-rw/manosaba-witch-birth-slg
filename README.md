# manosaba-witch-birth-slg

**魔法少女ノ魔女裁判** の二次創作テキストSLG（プロトタイプ）です。  
日本語タイトル：**大魔女受胎SLG**（大魔女受胎計画）

> **18禁（R-18）**  
> 性的表現・触手・妊娠・出産などを含みます。18歳未満の利用・閲覧を禁止します。

---

## 概要

牢屋敷に集められた魔女因子を持つ少女たち。  
ストレスによる魔女化ではなく、**大魔女を妊娠・出産させる**方針へ切り替わった世界が舞台です。

プレイヤーは、なぜか魔女因子を持つ一般の男性として連れてこられた存在です。

- **触手** … 大魔女受胎の高確率ルート（高ストレス）
- **プレイヤー自身** … 瞑想で因子を育て、エッチでも大魔女を狙える低〜中確率ルート
- 目的は誰かに大魔女を宿し出産まで至らせること。果たせば外へ、果たせねば封印や処刑など複数エンド

本リポジトリは **コンソール（ターミナル）上で動く Python 製プロトタイプ** です。

---

## 必要環境

- Python 3.10 以降を推奨（3.7+ でも動作する想定）
- 標準ライブラリのみ（追加パッケージ不要）

---

## 起動方法

```bash
cd manosaba-witch-birth-slg
python main.py
```

環境によっては `python3 main.py` を使用してください。

### タイトルメニュー

1. **最初から** … 名前入力 → あらすじ表示の有無 → ゲーム開始  
2. **ロード** … セーブスロットから再開  
3. **終了**

セーブは `saves/` 以下に保存されます。  
プレイヤー名の前回値は `saves/settings.json` に保持されます。

---

## 操作の概要

1日は **午前 / 午後 / 夜中** の3フェイズです。

| 時間 | 主な行動 |
|------|----------|
| 午前・午後 | 開発する／仲良くする／エッチする／休憩／体力トレーニング／テクニック向上／瞑想／アルバイト |
| 夜中 | 触手調教／触手交尾／就寝 |

- **開発Lv** … プレイヤーの「開発する」やオナニーで上昇。触手のストレス・体力消費を軽減する  
- **触手** … 受胎度・受精向け。開発Lvは上がらない。負荷が大きい  
- **瞑想** … 自己因子（0〜100）。積み重ねると触手に頼らない大魔女ルートが現実的に  

エンディングは条件達成後、システムメニューの **「エンディングへ」** から確定します（自動終了しない設計）。

詳細は同梱の仕様書を参照してください。
