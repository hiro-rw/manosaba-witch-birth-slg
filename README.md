manosaba-witch-birth-slg

魔法少女ノ魔女裁判 の二次創作テキストSLG（プロトタイプ）です。
日本語タイトル：大魔女受胎SLG（大魔女受胎計画）



18禁（R-18）
性的表現・触手・妊娠・出産などを含みます。18歳未満の利用・閲覧を禁止します。



概要

牢屋敷に集められた魔女因子を持つ少女たち。
ストレスによる魔女化ではなく、大魔女を妊娠・出産させる方針へ切り替わった世界が舞台です。

プレイヤーは、なぜか魔女因子を持つ一般の男性として連れてこられた存在です。





触手 … 受胎度を上げ、大魔女を宿せる身体へ改造する（高ストレス）



プレイヤー自身 … 瞑想で因子を育て、エッチで大魔女を狙うルート



目的 … 誰かに大魔女を宿し、発覚（報告）まで至らせること

果たせば外への道が開かれ、果たせねば封印や処刑など複数のエンディングがあります。

本リポジトリは コンソール（ターミナル）上で動く Python 製プロトタイプ です。
追加パッケージは不要で、標準ライブラリのみで動作します。



必要環境





Python 3.10 以降を推奨（3.7+ でも動作する想定）



標準ライブラリのみ（pip install 不要）



起動方法

cd manosaba-witch-birth-slg
python main.py

環境によっては python3 main.py を使用してください。

タイトルメニュー





最初から … 名前入力 → あらすじ表示の有無 → ゲーム開始



ロード … セーブスロットから再開



終了

セーブは saves/ 以下に保存されます。
プレイヤー名の前回値は saves/settings.json に保持されます。



遊び方

1日の流れ

1日は 午前 → 午後 → 夜中 の3フェイズで進みます。
各フェイズで1行動を選び、3フェイズ終了で次の日になります。







フェイズ



主な行動





午前・午後



目標への行動（仲良くする／エッチする／開発する など）
自分の行動（瞑想／アルバイト／テクニック向上）





夜中



触手調教（受胎度）／触手から因子を引き出す／就寝

システムメニューからステータス確認・セーブ・ロード・エンディング確定が行えます。

主な行動







行動



効果の概要





仲良くする



好感度上昇。ストレス回復の主手段。エッチの前提





エッチする



好感が足りないと不可。人間の子／大魔女の受精判定がここで行われる





開発する



ソフト／ノーマル／ハード。開発Lv上昇。触手やエッチの負荷を軽減





休憩



体力回復（ストレス軽減は小さめ）





体力トレーニング



最大体力を伸ばす





瞑想



自分の因子を安全に増やす（1〜10）





アルバイト



資金を増やす（テクニック向上の費用に使う）





触手調教



受胎度を上げる。ストレスと体力を消費。妊娠はしない





触手から因子を引き出す



自分の因子＋触手Lv上昇。受胎度は増えない

主要なパラメータ







パラメータ



意味





受胎度



0〜100。触手調教で上昇。100になるとエッチで大魔女が着床しやすくなる





好感度



仲良くするで上昇。低いとエッチ不可／行動の負荷が増える





ストレス



高いと魔女化が進む。仲良くする・休憩で軽減





開発Lv



開発するで上昇。触手調教やエッチのストレス・体力消費を軽減





因子（プレイヤー）



瞑想や触手から引き出すで上昇。大魔女受精の確率に影響





触手Lv



館全体の触手の強さ。上がるほど調教が苛烈になる（下がらない）





体力



行動で消費。0に近いと危険

クリアの目安





本命クリア … 誰かに大魔女を宿し、本人が妊娠に気づいて報告する（発覚）まで至らせる



出産はクリア必須ではありません（発覚後の演出として残っています）



条件を満たすとフラグが立ちます。システムメニューの 「エンディングへ」 から確定してください（自動では終わりません）

詳細な仕様・バランス・エンディング一覧は同梱の 大魔女受胎SLG_仕様書.md を参照してください。
